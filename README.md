# Nonlinear Equation Solver

Розв’язання нелінійних алгебраїчних рівнянь з комплексними числами.

Курсова робота з дисципліни «Об’єктно-орієнтоване програмування».

**КПІ · 1 курс · C# · .NET 9 · Avalonia UI**

[Усі навчальні роботи](https://github.com/nanzajjd/University-Labs)

## Завантаження та запуск

Потрібен .NET SDK 9 або сумісний новіший SDK з підтримкою `net9.0`.

```bash
git clone https://github.com/nanzajjd/Nonlinear-Equation-Solver.git
cd Nonlinear-Equation-Solver
dotnet run --project NonlinearAlgebraicEquationsComplexNumbers.csproj
```

У VS Code: `Git: Clone` → `https://github.com/nanzajjd/Nonlinear-Equation-Solver.git` → відкрити завантажену папку.
